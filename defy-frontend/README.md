# defy-frontend

15c 실시간 차량 시연 웹 프론트엔드입니다. Vite + TypeScript(프레임워크 없음)로 만들었습니다.

- 기본은 **샘플 데이터** 모드입니다. 화면 위쪽에 "샘플 데이터 — 실제 15c 출력 아님"이 표시됩니다.
- `?source=server`를 붙이면 서버 모드가 되고, 목업 서버나 실제 서버와 WebSocket으로 통신합니다.

## 준비

- **Node.js 24 이상.** 목업 서버(`mock/*.ts`)를 Node가 TypeScript 그대로 실행하기 때문입니다. nvm을 쓴다면 `nvm use`로 `.nvmrc`의 버전을 고를 수 있습니다.

```bash
git clone https://github.com/cksdyd3786/defy-frontend.git
cd defy-frontend
npm install
```

## 실행

### 샘플 모드 (서버 없이)

```bash
npm run dev
```

http://localhost:5173 을 엽니다. 처음에는 4단계 안내가 나오고, Enter 또는 아무 키로 넘깁니다.

- **샘플 재생:** 오른쪽 위 "테스트" 목록에서 고릅니다. 정적 확인 프레임도 같은 목록에 있습니다.
- **운전:** 물리 키보드로 합니다. W/A/S/D 운전, Q/E 깜빡이, 1~5 시나리오, 0 해제, R 초기화.

### 서버 모드 (목업 서버)

터미널 두 개가 필요합니다.

```bash
npm run mock   # 목업 서버 (기본 포트 8787, 환경변수 MOCK_PORT로 변경)
npm run dev    # Vite 개발 서버. /api 를 목업 서버로 프록시
```

http://localhost:5173/?source=server 를 엽니다.

- **개발용 도구:** 주소 끝에 `#debug`를 붙이면 메시지 로그 창과 [오류 일으키기] 시험 메뉴가 보입니다.
- **실제 서버에 연결:** `DEFY_API_TARGET=http://서버주소:포트 npm run dev`로 프록시 대상을 바꿉니다.
- **목업 서버는 실제 15c가 아닙니다.** 계약(`src/contracts.ts`) 형식만 흉내 냅니다.

### 서버 모드 (실제 15c 서버) · 자동 모드

```bash
npm run real   # 실제 15c 서버 (포트 8787). python 경로는 DEFY_PYTHON=python 처럼 지정 (real/README.md)
npm run dev    # http://localhost:5173/?source=server
```

자동 모드를 지원하는 서버(`GET /health`의 `auto_drive_available=true`)에 연결하면, 시작 화면 없이 바로 **자동 모드 세션**을 만듭니다.
- 생성 요청 본문은 `{"auto_drive": true, "auto_level": "high"}`입니다. 시드는 서버가 정하고, 엔진은 기본 rule입니다.
- 위험도는 `src/config.ts`의 `AUTO_START_LEVEL` 한 곳에서 바꿉니다(예: `'random'`).
- 목업처럼 자동을 지원하지 않는 서버이거나 health 요청이 실패하면, 전과 같이 `{}`로 직접 조종 세션을 만듭니다.
- **무작위와 시드는 가상 운전자의 입력 순서에만 쓰입니다.** 시뮬레이션 잡음(배경 흔들림·관측 잡음)은 매번 같습니다. 자동 상태 칸의 툴팁에도 같은 내용이 있습니다.
- **사람이 키나 명령을 보내면 서버가 바로 직접 조종으로 바꿉니다.** 자동 주행 중에는 자동 상태 칸에 "키를 누르면 직접 조종으로 바뀝니다"가 항상 보이고, 바뀐 뒤에는 "R을 누르면 자동 주행으로 돌아갑니다"가 보입니다.
- **개발·비교용 숨은 경로:** 주소에 `?mode=manual`을 붙이면(`?source=server&mode=manual`) 자동을 지원하는 서버에서도 `{}`로 직접 조종 세션을 만듭니다. 화면에는 노출하지 않으며, 직접 조종 회귀 비교에 씁니다.

자동 세션의 흐름과 눈으로 확인하는 방법:

1. `npm run real`과 `npm run dev`를 켠 뒤 http://localhost:5173/?source=server 를 엽니다. 바로 안내 4단계가 나오고, 말풍선에 "자동 모드: 안내를 끝내면 …" 한 줄이 더 붙습니다. 안내는 건너뛸 수 없습니다.
2. 안내를 끝내면 주행 화면 왼쪽 아래 도크에 **자동 · 높음 · seed (서버가 정한 값) / 보통 주행 (첫 대기 전)** 이 보입니다. 약 10초 뒤 **다음 이벤트 대기 · 다음 이벤트까지 n초** 로 바뀝니다.
3. 이벤트가 시작되면 **이벤트 중 · (종류)** 가 보입니다. 운전자가 누른 W/A/S/D는 키 그림에 **점선 하늘색 테두리**로 표시됩니다. 사람이 누른 키는 흰 바탕입니다.
4. 아무 운전 키(예: W)를 누르면 바로 **직접 조종으로 바뀜 · 사람 키 입력** 과 "R을 누르면 자동 주행으로 돌아갑니다"가 보입니다. Q/E·1~5·0이나 [시나리오 해제 (0)] 버튼으로 바뀌면 사유가 **사람 명령(Q/E·1~5·0)** 입니다.
5. R을 누르면 안내부터 다시 시작하고, 안내를 끝내면 같은 시드로 **보통 주행 (첫 대기 전)** 부터 자동 주행이 다시 시작됩니다.
6. 다른 창을 눌러 포커스를 옮기면 일시정지 카드가 나오고 그대로 멈춰 있습니다. 자동으로 재개하지 않으니 [재개]를 누릅니다.
7. **데이터 근거** 탭에 **입력 출처**(자동 / 직접 조종 · 사유)와 **자동 기록** 팝오버가 있습니다. 팝오버에는 시드·위험도와 서버가 보낸 최근 20개 기록이 들어 있습니다. 운전자의 시나리오 해제·깜빡이는 시나리오·로그 탭의 최근 로그에 기존 이벤트와 같은 모양으로 나옵니다.

## 알려진 한계

- **자동 모드는 rule로만 동작하고 rule에서만 검증했습니다.** 엔진(nmpc)을 고르는 UI는 없습니다.
- **실제 서버(`real/`)는 브리지 프로세스가 하나뿐이라, 명세 10.1의 nmpc 세션 격리 요구를 충족하지 못합니다.** 여러 세션을 동시에 쓰면 Python Session과 NMPC solver 상태를 같이 씁니다.
- 자동 모드 지원 여부를 보려고 서버 모드 시작 때 `GET /health`를 한 번 더 부릅니다(`?mode=manual`이면 부르지 않음). 직접 조종 세션의 생성 요청 본문은 전과 같은 `{}`입니다.
- 목업 서버는 자동 모드가 없습니다(`auto_drive_available=false`). 그래서 목업에서는 항상 직접 조종입니다.
- **자동 모드의 위빙은 이웃차가 자차 앞(약 25 m) 같은 차로로 들어온 뒤 시작합니다.** 위빙의 실제 흔들림은 표의 진폭보다 커서(1.2 m 단계는 한쪽 최대 약 2.6 m), 바깥 차로에서 시작하면 도로를 벗어납니다. 가운데 차로에서는 세 단계 모두 12초를 끝까지 흔듭니다(평균 폭 0.8 m 단계 1.7 m, 1.2 m 단계 3.6 m, 0.5 m 단계 1.4 m).
  - 대신 자차 바로 앞에서 흔들리므로 자차가 회피하는 경우가 많습니다(1.2 m 단계 14/18회). 최소 차체 간격은 1.15 m까지 좁아졌습니다. high, seed 7~9, 각 60분 측정에서 충돌과 도로 이탈은 0이었습니다.
  - 그래서 위빙 전에 차로 진입이 한 번 들어가는 셈입니다. 위빙에서는 깜빡이를 켜지 않습니다.

## 스크립트

| 명령 | 내용 |
|---|---|
| `npm run dev` | 개발 서버 (http://localhost:5173) |
| `npm run mock` | 목업 서버 (http://localhost:8787) |
| `npm run typecheck` | 타입 검사 |
| `npm run check:contracts` | `src/contracts.ts`가 원본 `../demo_v15c/docs/Defy_Tech_Spec_Contracts/web-demo-contracts.ts`와 같은지 확인합니다. 원본 폴더가 없으면 건너뜁니다 |
| `npm run build` | 계약 확인 → 타입 검사 → `dist/` 빌드 |
| `npm run preview` | 빌드 결과 미리보기 (http://localhost:4173) |

## 폴더

| 경로 | 내용 |
|---|---|
| `src/contracts.ts` | 계약 타입. 원본 사본이므로 **직접 고치지 않습니다** |
| `src/contract-access.ts` | 계약 필드에 접근하는 유일한 곳 |
| `src/source/` | 샘플 재생, WebSocket 클라이언트, 오류 처리 규칙 |
| `src/input/` | 키보드 입력과 서버로 보내는 메시지 |
| `src/view/` | 도로·그래프·게이지·패널 그리기 |
| `src/ui/` | 안내, 정지, 오류, 연결 화면과 화면 문구(`text-ko.ts`) |
| `mock/` | 목업 서버 |
